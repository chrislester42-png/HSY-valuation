# The Hershey Company (HSY) valuation project

> Open this note every time you sit down to work. It is the map of everything the team knows.

## How this vault works

- **01 Sources**: one note per primary document (a 10-K, a press release, a dataset, an article). Each has a URL or a file in `_files/`.
- **02 Atomic Notes**: one fact per note, with the exact figure, why it matters, a status, a tier, and a link to the source note it came from.
- **03 Drafts**: the milestone memos while they are being written, and any working sections.
- **04 Final Deliverables**: the versions that were submitted to Canvas.
- **05 Questions**: what we still need to find out, and what we found.
- **06 Templates**: the shape every note follows. Claude fills them in.
- **07 Daily**: optional session notes.

Every number on the site points at an atomic note here. Every atomic note points at a source note. That chain is the Knowledge Bank (Module 3).
