Put downloaded filings and datasets here: the 10-K and 10-Q as .htm or .pdf, Damodaran spreadsheets, the earnings release. Each file gets a source note one folder up.

Vendor data exports (a FactSet download, for example) go here too, but git ignores spreadsheets in this folder, so they stay on your computer and never reach GitHub. Their licenses do not allow publishing them. The source note in `01 Sources` is what gets committed.
