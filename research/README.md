# The research vault

This folder is an Obsidian vault. Open Obsidian, choose Open folder as vault, and pick this `research` folder (not the repo root). Turn off Restricted Mode if it asks; no community plugins are required. Start at `00 Project Home`.

Claude creates and edits the notes here through the Code tab. Obsidian is how you read them: click a link, see the graph, follow a fact back to its source. In Module 3 this vault is baked into the site's Knowledge Bank page.

Filenames must not contain `$ % / : ?` and renaming a note outside Obsidian breaks its links.
