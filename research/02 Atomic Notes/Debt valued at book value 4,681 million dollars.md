# Debt valued at book value 4,681 million dollars

The WACC uses Hershey's book value of long-term debt at December 31, 2025, 4,681 million dollars, as the market value of its debt.

It sets the debt weight of 12.6 percent. If the notes trade well below par, market value would be lower and the debt weight slightly smaller.

Estimate: Chris Lester judged book value a reasonable stand-in for market value because Hershey's long-term debt is fixed-rate notes. The 4,681 figure itself is a workbook number (Detail Data, long-term debt, 2025A).
