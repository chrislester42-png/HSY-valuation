# Skills

Files Claude reads when a prompt tells it to. They are not loaded on their own.

- `design-taste/SKILL.md`: the "design-taste-frontend" skill by Leonxlnx (https://github.com/Leonxlnx/taste-skill), MIT license, copied 2026-10-04. It is written for React and Tailwind sites and for landing pages; this site is plain HTML, CSS, and JavaScript and is a research report, so the design prompts in PROMPTS.md say which of its sections apply and what must not change (numbers, section ids, nav labels, Fact chips, sliders, tables).
- `site-design/DESIGN.md`: the brief for the Module 3 redesign (every section one screen, like a slide; chart-first Financials; one palette for every page). The redesign prompt in PROMPTS.md has Claude read it with the taste skill.
